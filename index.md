# Privacy Policy for Modbus Pro

Effective date: January 2026

Modbus Pro does not collect, store, or share any personal or sensitive user data.

The application communicates only with user-configured industrial devices using local or remote network connections for Modbus TCP communication. All network communication is initiated by the user and occurs directly between the device running the app and the configured industrial equipment.

Modbus Pro does not use analytics, advertising services, tracking technologies, or third-party SDKs that collect user data.

No data is transmitted to the developer or any third party.
